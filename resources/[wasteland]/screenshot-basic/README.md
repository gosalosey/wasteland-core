# screenshot-basic (built)

The official CitizenFX screenshot resource, built from
https://github.com/citizenfx/screenshot-basic (commit 5e89d4a) with its own
webpack configs, so it runs without the yarn/webpack builder resources.
License: MIT (LICENSE). Used by wasteland_survival for the HUD character
picture (client export `requestScreenshot`). Keep `ensure screenshot-basic`
before the Wasteland resources in server.cfg.
